# DeyeWatch — програма для Windows і Linux

Сирці програми з графічним інтерфейсом (Python 3.9+, PySide6).

- Можливості, скріншоти й завантаження — у [головному README](../README.md).
- Встановлення — [docs/installation.md](../docs/installation.md).
- Структура коду, збірка `.exe` / `.deb`, скріншоти — [docs/development.md](../docs/development.md).

Швидкий запуск із сирців:

```bash
pip install -r requirements.txt
```

```bash
python deyewatch.py
```
