# DeyeWatch для Android — у розробці

> ⚠️ Попередня версія: сирці ще не збиралися й не перевірялися на телефоні. Готового APK поки немає.

Нативний застосунок (Kotlin, Jetpack Compose) з тими самими можливостями, що й DeyeWatch для ПК:

- **удома** — дані напряму з WiFi-стіка (Solarman V5, порт 8899), автопошук стіка в мережі;
- **поза домом** — останні дані з Deye Cloud (із затримкою 5–15 хв);
- **фонове стеження** й сповіщення: світло зникло / з'явилося, низький заряд, генератор, немає даних;
- екрани «Огляд» (стан, смуга 24 годин, схема потоків, батарея, графік), «Відключення», «Налаштування»;
- імпорт файлу налаштувань з DeyeWatch для ПК.

## Збірка

Потрібні JDK 17 і Android SDK (platform 35). Зі встановленим Gradle 8.11+:

```bash
cd android && gradle assembleRelease
```

Для підпису релізу створіть `android/keystore.properties` (у репозиторій не потрапляє):

```properties
storeFile=deyewatch.jks
storePassword=…
keyAlias=deyewatch
keyPassword=…
```
