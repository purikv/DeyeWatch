## Що потрібно

- **Гібридний інвертор Deye** з WiFi-стіком Solarman (див. [Сумісність](../README.md#сумісність)).
- **Комп'ютер у тій самій мережі**, що й стік (той самий роутер; ретранслятори Wi-Fi не заважають).
- Для сповіщень під час відключення роутер і комп'ютер мають живитися від резервного виходу
  інвертора (LOAD) або від ДБЖ — інакше разом зі світлом зникне й зв'язок.

## Windows

Підтримуються Windows 10 і 11 (64-біт).

1. Завантажте **`DeyeWatch.exe`** з [останнього релізу](https://github.com/purikv/DeyeWatch/releases/latest).
2. Перенесіть файл у постійне місце, наприклад `C:\Program Files\DeyeWatch\` або `%LOCALAPPDATA%\DeyeWatch\`.
   Програма портативна: інсталятор не потрібен, Python теж.
3. Запустіть. Якщо Windows SmartScreen покаже «Windows захистив ваш ПК» — натисніть
   **«Докладніше» → «Виконати в будь-якому разі»** (файл не має платного цифрового підпису).
4. У *Налаштування → Інтерфейс* увімкніть **«Запускати разом із системою»**.

Налаштування й історія зберігаються в `%APPDATA%\DeyeWatch`.

## Linux: пакет .deb

Для Ubuntu 22.04+, Debian 11+, Linux Mint 21+ та похідних (x86_64).

```bash
sudo apt install ./deyewatch_amd64.deb
```

Пакет містить усе потрібне, зокрема бібліотеку PySide6 для двох поколінь систем, тому
**встановлення не потребує інтернету**: під час встановлення створюється окреме середовище Python у
`/opt/deyewatch`, у меню програм з'являється ярлик DeyeWatch, а в терміналі — команда `deyewatch`.
Системні бібліотеки Qt `apt` доставить сам.

> **GNOME (Ubuntu):** іконка в треї з'являється лише з розширенням
> «AppIndicator and KStatusNotifierItem Support» (в Ubuntu воно ввімкнене за замовчуванням).

Налаштування й історія зберігаються в `~/.config/deyewatch`.

## Linux: архів для будь-якого дистрибутива

Для Fedora, Arch, openSUSE, а також ARM64 (наприклад, Raspberry Pi 4/5 з 64-бітною ОС).
Потрібні Python 3.9+ і модуль `venv`; встановлення без прав root, у домашню теку.

```bash
tar xzf DeyeWatch-linux.tar.gz
```

```bash
cd DeyeWatch-linux && sh install.sh
```

Інсталятор створює власне середовище Python у `~/.local/share/deyewatch`, завантажує PySide6
(≈ 100 МБ, потрібен інтернет), додає ярлик у меню і команду `~/.local/bin/deyewatch`.
Якщо бракує системних бібліотек Qt, інсталятор підкаже точну команду для вашого дистрибутива.

## Запуск із сирців

Будь-яка ОС із Python 3.9+:

```bash
git clone https://github.com/purikv/DeyeWatch.git
```

```bash
cd DeyeWatch/desktop && pip install -r requirements.txt
```

```bash
python deyewatch.py
```

## Перший запуск

1. **Пошук стіка.** Якщо стік ще не вказано, програма сама шукає його в мережі (UDP-запит
   Solarman на порт 48899 до кожної адреси підмережі) і бере перший знайдений. Те саме робить кнопка
   *Налаштування → Підключення → «Знайти автоматично»*. Можна й вручну: IP-адреса стіка (видно в
   списку клієнтів роутера) та **серійний номер стіка** — 10 цифр на його наклейці (це не номер інвертора!).
2. **«З чого почати».** На Огляді з'явиться картка з кроками: перевірити ємність батареї й
   мінімальний заряд, увімкнути автозапуск, за бажанням — Telegram і Deye Cloud. Кнопка
   «Налаштувати» біля кожного кроку відкриває потрібний розділ.
3. **Порада.** Закріпіть за стіком постійну IP-адресу в роутері (на ASUS:
   *LAN → DHCP Server → Manual Assignment*). Якщо адреса все ж зміниться, програма знайде стік
   за серійним номером сама.

## Автозапуск

*Налаштування → Інтерфейс → «Запускати разом із системою»* — перемикач зберігається одразу.
Під ним видно фактичний стан у системі:

- **Windows** — запис у `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Якщо автозапуск
  вимкнено в *Диспетчері завдань → Автозавантаження*, програма про це попередить (увімкнути його
  там може лише користувач).
- **Linux** — файл `~/.config/autostart/deyewatch.desktop`.

Під час кожного запуску програма звіряє налаштування із системою: якщо файл програми перенесли,
запис автозапуску оновиться сам.

## Оновлення

- **Windows:** закрийте програму (іконка в треї → «Вийти») і замініть `DeyeWatch.exe` новим.
- **.deb:** `sudo apt install ./deyewatch_amd64.deb` з новою версією.
- **Архів:** розпакуйте новий архів і знову виконайте `sh install.sh`.

Налаштування й історія при оновленні зберігаються.

## Видалення

- **Windows:** вимкніть автозапуск, закрийте програму, видаліть `DeyeWatch.exe` і, за бажанням, теку
  `%APPDATA%\DeyeWatch`.
- **.deb:** `sudo apt remove deyewatch` (налаштування в `~/.config/deyewatch` лишаються).
- **Архів:** `sh install.sh --uninstall`.
